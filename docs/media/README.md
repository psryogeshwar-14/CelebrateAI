# CelebrateAI Media & Architecture Diagrams

This directory contains visual architectural and interface assets for CelebrateAI:

| Asset | Description |
|---|---|
| [`01-landing-hero.svg`](./01-landing-hero.svg) | High-fidelity vector preview of the CelebrateAI Landing Page and Bengaluru Demo cards. |
| [`03-dashboard-overview.svg`](./03-dashboard-overview.svg) | High-fidelity vector preview of the Event Command Center, ticking countdown, KPIs, and tonal budget donut chart. |

These assets represent the warm neutral (`#fafaf9`), ink text (`#1c1917`), and saffron-gold (`#d97706`) visual design guidelines required by PromptWars Challenge 5.
